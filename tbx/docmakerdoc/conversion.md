# Markdown conversion

DocMaker uses the bundled [cmark-gfm](https://github.com/github/cmark-gfm) MEX to convert Markdown to HTML. Conversion runs locally, works offline, and does not require a service, access token, or converter setting.

## Platform support

The bundled MEX currently supports Windows x64. On other platforms, `docconvert` and `docindex` report that a compatible cmark-gfm MEX is unavailable.
